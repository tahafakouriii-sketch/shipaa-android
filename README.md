# شیپا — اپ اندروید

نسخه بومی آزمایشی ۰٫۲، متصل به WordPress / WooCommerce / Studiare.

ساخت: GitHub Actions → **Shipaa native APK** → **Shipaa-Native-0.2-APK**.

رابط فارسی، دوره‌های مجاز، پخش ویدیو با ادامه از آخرین لحظه، دانلود MP4 و پخش آفلاین.

[وضعیت، محدودیت‌ها و معیار پذیرش](docs/native-v0.2.md)

ماژول فعال `app` است. پوشه `android-app` نمونه قدیمی و خارج از build است.
هیچ کلید مدیریتی یا رمز کاربر در اپ یا مخزن قرار نمی‌گیرد.
