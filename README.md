# شیپا | اپ اندروید

پروژه متن‌باز توسعه رابط آموزش‌محور شیپا برای اندروید، متصل به وب‌سایت WordPress + WooCommerce در https://shipaa.ir.

## وضعیت

**نسخه آغازین (scaffold)** — هنوز APK ساخته نشده و اتصال حساب کاربری/دوره‌های من پیاده‌سازی نشده است.

## ساختار

- `app/index.html`: پوسته اولیه فارسی، راست‌چین و واکنش‌گرا
- `app/manifest.webmanifest`: تنظیمات اولیه PWA
- `docs/roadmap.md`: نقشه راه اتصال واقعی به وردپرس، امنیت و بسته اندروید

## اصول

- هیچ اطلاعات حساس، کلید API، اطلاعات کارت بانکی یا رمز کاربران نباید در GitHub ثبت شود.
- دسترسی به محتوای دوره‌های خریداری‌شده فقط پس از احراز هویت و بررسی مجوز در **سرور وردپرس** انجام می‌شود.
- این پروژه از سایت اصلی مستقل است و نصب یا استقرار خودکار در وردپرس انجام نمی‌دهد.
- ساخت APK با Bubblewrap/TWA پس از میزبانی HTTPS، Web App Manifest، service worker، اثبات مالکیت دامنه و آزمون ورود قابل انجام است.

## آغاز

`app/index.html` را برای دیدن نمونه اولیه باز کنید. این صفحه فعلاً یک پیش‌نمایش است و به معنی اپ منتشرشده نیست.
