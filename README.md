# شیپا — اندروید ۱٫۰ آزمایشی

رابط بومی فارسی با فونت وزیرمتن، رنگ‌های سبز شیپا، خانه، کاوش و جست‌وجوی دوره، یادگیری من، دانلودها و حساب کاربری.

ساخت: GitHub Actions → **Shipaa native APK** → **Shipaa-1.0-beta1-APK**. فایل ZIP را باز و `app-debug.apk` را نصب کنید. این خروجی آزمایشی است؛ انتشار عمومی نیازمند کلید امضای پایدار متعلق به مالک است.

- دوره‌ها و جلسات مجاز از WordPress / WooCommerce / Studiare؛ کنترل دسترسی روی سرور.
- پخش MP4، تغییر سرعت، ادامه تماشا، دانلود و پخش آفلاین؛ حذف دانلودها هنگام خروج یا تغییر حساب.
- API نسخه ۱٫۰: فهرست عمومی، پروفایل و سفارش‌های کاربر جاری. ورود، ثبت‌نام دوره، پرداخت/رسید، کتابخانه و خدمات تکمیلی از صفحات واقعی سایت در WebView انجام می‌شوند.
- `server/native-api.php` نسخه جدید رابط است و باید جایگزین کد snippet شماره ۱۱۰ شود (بدون تگ آغاز PHP). نسخه ۱٫۰ روی سایت فعال شده و catalog، profile، orders و مجوز درس با پاسخ زنده بررسی شده‌اند. در استقرار بعدی، فعال‌سازی زنده باید با پاسخ `api_version: 1.0` در session و پاسخ موفق catalog تأیید شود. صرف ساخت APK فعال‌سازی سرور را ثابت نمی‌کند.

هیچ رمز یا کلید مدیریتی در اپ وجود ندارد. دانلودها DRM ندارند؛ فایل‌های HLS و DRM در این نسخه پشتیبانی نمی‌شوند.

## بررسی‌ها

CI شامل ساخت، Android Lint، آزمون جداسازی اطلاعات و مجوز جلسات در PHP، و آزمون جابه‌جایی صفحات مهمان در شبیه‌ساز است. تصاویر و گزارش شبیه‌ساز در `Shipaa-UI-verification` قرار می‌گیرند. آزمون شبیه‌ساز ورود واقعی یا پرداخت را انجام نمی‌دهد.

پیش از انتشار عمومی: ورود با حساب واقعی فراگیر، صحت دوره خریداری‌شده، دانلود کامل، حالت پرواز و ادامه تماشا، بارگذاری رسید و نتیجه ثبت‌نام روی گوشی واقعی تأیید شوند.

ماژول فعال `app` است. پوشه `android-app` نمونه قدیمی و خارج از build است.
